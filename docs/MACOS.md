# macOS 安装

支持 Apple Silicon、macOS 14+。按 [README 的 Mac 安装步骤](../README.md#mac-从源码运行) 安装依赖、模型并运行或打包。

- 模型安装：`pnpm setup:model`；完成后点击偏好设置里的“重启模型”。
- 默认快捷键：`⌘⇧Space`。单击右 Command 是可选映射，见 [快捷键说明](SHORTCUTS.md)。
- 首次使用，在系统提示中允许麦克风；自动输入需要系统设置中的“隐私与安全性 → 辅助功能”权限。
- 模型加载通常需要几秒，状态为“本地模型已就绪”后再开始录音。
- 应用关闭窗口后留在菜单栏；从菜单栏选择“退出麦麦”才会退出。
- 本地签名构建没有 Apple Developer ID 公证。新安装或签名变化时可能需要重新授权。

升级前先退出旧应用并备份本地数据库。不要把个人数据库、音频或密钥上传到 Git。
