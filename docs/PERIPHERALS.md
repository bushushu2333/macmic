# 外设适配指南（麦克风设备 + 翻页器/小键盘按键）

macmic 0.4.0 起支持两类外设，全部在 **设置 → 麦克风与外设** 中完成配置：

1. **指定麦克风设备**——例如 DJI 麦克风的接收器（USB / 蓝牙接入电脑后就是一个系统麦克风）。
2. **外接按键**——例如三键翻页器（Free2 / Free3 等）、可编程小键盘等一切以"普通键盘"身份工作的 HID 设备。

---

## 一、麦克风设备（DJI 麦等）

1. 把 DJI 接收器插到电脑（或通过蓝牙连接），系统声音设置里能看到它。
2. 打开麦麦 → 设置 → 麦克风与外设 → **麦克风设备**，在下拉框里选中它（名称一般带 DJI / DJI Mic 字样）。
3. 选择立即保存，下次听写生效。

行为说明：

- 只锁定了**这一台设备**；设备不在线（没插接收器 / 关机）时，麦麦自动改用系统默认麦克风，不会听写失败。
- 锁定的设备重新接入后，下次听写自动恢复用它，无需重新设置。
- 选回「系统默认」即恢复出厂行为（跟随系统输入设备）。

## 二、外接按键（三键翻页器 Free2/Free3 为例）

翻页器推到 **P 档**后就是一个蓝牙键盘，每个键发什么按键值由厂商"自定义软件"决定。麦麦侧只需要把"某个按键值 → 某个动作"绑定起来。

### 第 1 步：在厂商软件里录制按键值

按厂商教程（自定义软件 → 选 P 档 → 选择按键 → 录制），把三个键分别设为（推荐的"录音 / 删除 / 发送"布局）：

| 翻页器按键 | 建议录制的按键值 | 在麦麦里的默认动作 |
| --- | --- | --- |
| 键 1（录音） | **F13** | 开始 / 结束听写 |
| 键 2（删除） | **F14** | 取消本次听写 |
| 键 3（发送） | **F15** | 完成并输入（发送） |

用法：键 1 开始说话；说完按键 3（发送）文字上屏；不想发了按键 2（删除）丢弃。键 1 再按一次同样可以完成，两种习惯都顺手。

- F13–F24 是普通键盘没有的键，绑定后不会和你电脑上任何软件冲突。
- 厂商软件不支持 F13+ 时，选其他**单键**（如 `F9`、`PageDown`）也可以，在麦麦里把对应动作改绑到那个键即可；**不要录多键宏**，麦麦只绑定单键（可带修饰键，如 Shift+F9）。
- 录完拔掉数据线，翻页器推到 P 档开机，电脑蓝牙搜索 `Free3-P` 配对（之前配对过就先删除旧配对再连）。

### 第 2 步：在麦麦里绑定

1. 麦麦 → 设置 → 麦克风与外设，三个动作各占一行，显示当前按键与状态。
2. 点「改键」，然后**按下翻页器上对应的键**（例如键 1 = F13），显示的按键值会自动填入并保存。
3. 按 Esc 可放弃本次改键。

状态说明：

- **已生效**：系统接受注册，按键全局可用（任何应用在前台都有效）。
- **被占用**：这个按键值已被系统上其他应用注册，换一个键重新绑定即可。

### 三个动作是干什么的

- **开始 / 结束听写**（录音键）：与左右 Alt / 右 ⌘ 轻按完全等效，按一下开始，再按一下完成并自动输入。
- **取消本次听写**（删除键）：等同 Esc，丢弃正在进行的听写。
- **完成并输入 / 发送**（发送键）：只在录音进行中生效——立刻收尾、识别并输入；空闲时按下不产生任何动作。
- **开启 / 关闭文字整理**：一键切换"识别后是否让 AI 整理标点、去除口头重复"，切换时弹系统通知确认当前状态。（想用它就把某个键改绑到这个动作。）

## 三、细节与故障排查

- **按键没反应**：确认翻页器开机且蓝牙已连（系统蓝牙列表里在）；确认在麦麦里该行显示「已生效」；若录的是多键宏，请改成单键。
- **被占用**：换一个键值重新录制（厂商软件里改），再到麦麦里改键。
- **改键时按了键没填进去**：录制期间麦麦会临时让出所有全局快捷键（包括备用快捷键），结束录制后自动恢复；若窗口失焦，录制自动取消，重新点「改键」即可。
- **电脑睡眠唤醒后按键失效**：麦麦会在唤醒后自动重新注册，等待几秒；仍无效时打开设置页任意改键一次触发重建。
- 麦麦不读取、不上报外设型号与按键内容，只注册你明确绑定的按键值。
